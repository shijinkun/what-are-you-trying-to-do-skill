# what-are-you-trying-to-do

一个帮助任何人在向 AI 提问前弄清“到底想干啥”的通用 Skill。它把模糊的想法整理成目标明确、范围清楚、成功标准可检查的任务，让 AI 先确认问题，再开始回答、分析、写作、编程或制定方案。

## 核心能力

- 构念效度（一个心理学概念）：用户说的概念，是否被合适的可观察目标或指标表示；
- 测量不变性：需要比较的对象、案例或结果，是否具备可比较边界；
- 证据校准：结论措辞不超过实际证据能够支持的范围；
- 动态追问：每轮只提出一个最高价值问题，不重复已确认内容；
- 启动授权：区分边界已验证、尚未授权和用户接受受限精度；
- 结构化交接：输出统一 JSON 合同，供下游系统读取。

它不预设任何学科、材料、工具、指标或工作流程。具体内容必须来自提问者或其提供的上下文。

## 安装

将 `what-are-you-trying-to-do` 目录放入目标 Agent 的 skills 目录，并确保目录中包含 `SKILL.md`。运行时根据描述中的触发条件加载该 Skill。

## 安全边界

Skill 只负责澄清问题和确认边界，不替用户做未经确认的假设，不自动承诺结果，也不泄露隐藏思维过程。
